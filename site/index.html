Hello, Medicare

A static page born in a pull request, approved in Jira, and served from Akamai NetStorage — the whole path an onboarding engineer walks on day one.

How this page got here

  1. Repository created under governance, sample code arrived by pull request.
  2. The merge was approved through a WETGSREOPS Jira ticket — filed and watched by the onboarding agent.
  3. Content uploaded to NetStorage over the HTTP API (the enclave-viable path).
  4. Served by the wetgsre-demo-test-site Akamai property.

Instrumentation

Feature flags via LaunchDarkly; Real User Monitoring via Datadog (US1-FED). Client keys are injected at deploy — placeholders below never hold real values.
